# CLI Calculator — Git Merge Conflict Demo

A small Python command-line calculator built for **UCS745 Cloud and DevOps – Lab Assignment Q1**.
The goal of the project is to practise a real Git/GitHub workflow: `init`, `add`, `commit`,
`push`, `pull`, branching, merging and resolving an intentional merge conflict.

## Features

- Basic operations: addition, subtraction, multiplication, division
- Advanced operations: power (`^`) and modulo (`%`)

## Usage

```bash
python calculator.py
calc> 12 * 3
36.0
calc> q
```

## Running the tests

python -m unittest -v
